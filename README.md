## ✨ Funcionalidades

O portfólio foi estruturado para proporcionar uma experiência de navegação simples, organizada e intuitiva.

### 📱 Layout Responsivo

Interface adaptável a diferentes resoluções de tela, incluindo computadores, tablets e smartphones.

### 🧭 Menu de Navegação

Menu responsivo que permite acessar rapidamente as seções da página.

### 🗂️ Filtro Dinâmico de Projetos

Sistema desenvolvido em JavaScript que organiza os projetos por categorias:

- **Todos:** apresenta os seis projetos.
- **Web:** apresenta projetos desenvolvidos para a internet.
- **Python:** apresenta projetos de programação em Python.

Os filtros utilizam atributos `data-filter` e `data-category`.

### 🌗 Alternância de Tema

Funcionalidade para alternar a aparência visual do portfólio.

O JavaScript aplica a classe `light-theme` ao elemento `body`, permitindo alternar entre os estilos disponíveis.

A preferência pode ser armazenada utilizando `localStorage`, quando disponível.

### 🎬 Animações de Entrada

Utilização da API `IntersectionObserver` para identificar elementos que entram na área visível da página e aplicar efeitos de apresentação.

### 🖱️ Efeitos Hover

Aplicação de transições CSS para melhorar a experiência visual.

Os elementos interativos podem apresentar:

- Ampliação suave de 5%.
- Mudanças de destaque visual.
- Transições de transformação.
- Realce dos cards e links.

### 📧 Formulário de Contato

Formulário que prepara uma mensagem de e-mail utilizando o aplicativo configurado no dispositivo do visitante.

Para utilizar essa funcionalidade, é necessário configurar a constante `EMAIL_DESTINO` no arquivo `script.js`.

**Observação:** o formulário não utiliza banco de dados nem serviço próprio de envio de mensagens.

## 📁 Estrutura do Projeto

```text
projeto_portfolio/
│
├── index.html
│
├── style.css
│
├── script.js
│
├── README.md
│
└── assets/
    │
    └── logo.png
```

**Descrição dos arquivos:**

| Arquivo | Finalidade |
|---|---|
| `index.html` | Estrutura principal do portfólio |
| `style.css` | Aparência, animações e responsividade |
| `script.js` | Funcionalidades e interatividade |
| `README.md` | Documentação do projeto |
| `assets/logo.png` | Identidade visual do portfólio |

A estrutura apresentada considera o logotipo dentro da pasta `assets`. O caminho no HTML deve corresponder à localização real da imagem.

## ⚙️ Como Executar o Projeto

### 1. Clonar o repositório

```bash
git clone https://github.com/marcelosantosguaruja/projeto_portfolio.git
```

### 2. Acessar a pasta

```bash
cd projeto_portfolio
```

### 3. Executar

Abra o arquivo `index.html` em um navegador.

Também é possível utilizar a extensão **Live Server** do Visual Studio Code para visualizar o projeto durante o desenvolvimento.

Como o portfólio é estático, não é necessário instalar um servidor de aplicação ou configurar um banco de dados.

## 🌍 Publicação no GitHub Pages

Para publicar ou atualizar o portfólio:

1. Acesse o repositório no GitHub.
2. Envie os arquivos do projeto.
3. Abra **Settings**.
4. Selecione **Pages**.
5. Em **Build and deployment**, escolha **Deploy from a branch**.
6. Selecione a branch `main`.
7. Escolha a pasta `/ (root)`.
8. Clique em **Save**.
9. Aguarde a publicação.

O endereço de acesso é:

https://marcelosantosguaruja.github.io/projeto_portfolio/

**Importante:** os nomes dos arquivos e seus caminhos devem respeitar letras maiúsculas e minúsculas para evitar erros de carregamento no GitHub Pages.
